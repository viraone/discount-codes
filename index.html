Lowest-price checklist

  1. Grab a code from the coupon sites — try 2–3, most codes are store-specific.
  2. Stack cashback — activate Rakuten / TopCashback before checkout for 1–10% back.
  3. Check price history — CamelCamelCamel & Keepa show if today's price is a real deal.
  4. Try open-box / refurbished — often 15–30% off with a warranty.
  5. Ask for a price match — Best Buy, Target, Walmart and Amazon all match each other.
